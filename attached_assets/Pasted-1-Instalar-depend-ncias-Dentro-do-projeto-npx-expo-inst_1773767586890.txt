Criar OAuth Client ID

Escolha:

Tipo: Web application (para Expo funciona melhor)

Adicione:

https://auth.expo.io/@seu-usuario/seu-app
🧠 3. Código básico (Expo)
import * as Google from 'expo-auth-session/providers/google';
import * as WebBrowser from 'expo-web-browser';
import { useEffect } from 'react';
import { Button } from 'react-native';

WebBrowser.maybeCompleteAuthSession();

export default function Login() {
  const [request, response, promptAsync] = Google.useAuthRequest({
    expoClientId: 'SEU_EXPO_CLIENT_ID',
  });

  useEffect(() => {
    if (response?.type === 'success') {
      const { authentication } = response;
      console.log(authentication.accessToken);
    }
  }, [response]);

  return (
    <Button
      title="Entrar com Google"
      disabled={!request}
      onPress={() => promptAsync()}
    />
  );
}
🔗 4. O que fazer com o token?

Depois que receber o accessToken, você tem 2 caminhos:

✔️ Simples (local)

Salva no app (AsyncStorage)

Usa como sessão

✔️ Profissional (recomendado)

Envia pro seu backend

Backend valida com Google

Cria sessão própria (JWT)

⚠️ Problemas comuns (especialmente no Replit + Expo Go)

Você comentou que usa o Expo Go, então atenção:

❗ 1. Redirect URI

Tem que bater exatamente com:

https://auth.expo.io/@seu-usuario/seu-app
❗ 2. Expo Go limitações

O Google pode bloquear se não estiver bem configurado.
