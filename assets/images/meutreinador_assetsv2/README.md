# Meu Treinador — pacote de design atualizado

## Conteúdo
- `mockups/`: dez telas conceituais — cinco telas principais e cinco telas pré-login (três etapas de onboarding, login e cadastro).
- `icons/`: ícones SVG editáveis para navegação, treino, câmera, onboarding, email e autenticação.
- `components/`: exemplos SVG reutilizáveis de botões, campos, progresso, linha de conta, métricas e opção selecionada.
- `DESIGN_TOKENS.md`: paleta, tipografia, espaçamento e notas de interface.
- `documentacao_design_meu_treinador.docx`: documentação ilustrada atualizada.

## Sobre os assets
Os mockups são imagens rasterizadas. O pacote não contém os arquivos de projeto originais nem as fontes das ilustrações/fotografias que aparecem nos mockups. Os ícones e componentes SVG fornecidos são recriações vetoriais editáveis, coerentes com a direção visual, e não extrações exatas dos pixels das telas.

## Uso
Os ícones usam `currentColor` e `viewBox` 24 × 24. Se a ferramenta não suportar `currentColor`, substitua-o por cor explícita. Os componentes são exemplos de referência e podem ser adaptados ao sistema de layout da plataforma.

As cores são aproximações de design; validar contraste, acessibilidade, tipografia e regras do produto antes da implementação.
